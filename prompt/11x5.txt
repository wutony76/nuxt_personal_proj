# 11x5  11選5新增

## 0. 命名慣例

「11x5」開頭是數字，不能直接當 JS/TS 常數、型別、函式名稱前綴
（同專案內 6HC 用 `LHC` 代稱的做法）。

本專案一律用 `X5` 代稱 11 選 5：
- 常數／型別／函式：`X5_xxx`、`X5CD_xxx`、`X5OF_xxx`
- composable：`useX5`
- 檔名：`x5.ts`、`x5-cd.ts`、`x5of.ts`（比照 `ssc.ts` / `ssc-cd.ts` / `sscof.ts`）

檔名／路由（頁面、資料夾）仍可用 `11x5` 原名（同 `6hc-cd.vue` 開頭帶數字沒問題），
只有「JS/TS 識別字」才需要換成 `X5`。

## 6. 彩池機制（Jackpot）

需求原文：「增加支援彩池機制，彩池相關設定需要與玩法保持正確關聯」。

11x5-**CD**（信用盤）需支援彩池機制（比照既有慣例，彩池只接在信用盤，官方盤是固定賠率不接彩池——
6hc-cd／ssc-cd／k3-cd／pk10-cd／eggs 皆是如此）。

**不是新發明一套彩池，是接上專案既有的泛用爆池骨架**（`shared/config/jackpot.ts`），
完整參考案例見 `openspec/reference/eggs-jackpot-plan.md`（PC蛋蛋接彩池的完整記錄：
決策過程、檔案改動清單、驗證清單），11x5-CD 接彩池的做法幾乎是同一套，只是彩種判定與觸發條件要重新分析。

### 6.1 既有架構（直接複用，勿重造）

| 層 | 檔案 | 職責 |
|---|---|---|
| 泛用核心 | `shared/config/jackpot.ts` | `JackpotSettings` / `JackpotRow` / `JackpotHitRecord` 型別 + `buildJackpotShares()` 純函式 |
| 彩種判定 | `shared/config/x5-cd.ts` | 新增 `X5_JACKPOT_SETTINGS`／`x5JackpotHit()`／`x5JackpotLabel()`（比照 `ssc-cd.ts` 的 `SSC_...`／`eggs-cd.ts` 的 `EGGS_...`） |
| 看板設定 | `shared/config/x5cd/plays.js` + `helpers.ts` | 注項宣告 `weight`（group 層預設＋item 層覆寫）；`helpers.ts` 補 `x5JackpotWeightOf()` |

金流兩條獨立的線（比照 `k3Cd.ts` / `eggs.ts`）：

```
下注  playBets()          → issueJackpotMap[issue] += amount * rakeRatio
開獎  settleIssuePrize()  → pool = issueJackpotMap[issue] + carryJackpot
                          → triggered ? 發 pool * payoutRatio : 全部滾存
                          → carryJackpot = jackpot.remain；issueJackpotMap[issue] = 0
```

### 6.2 需要拍板的決策（不可自行假設，動工前先確認）

1. **爆池觸發條件**：既有彩種的判準是「看板上真的押得到、機率與 6hc-cd 特別號開 49（≈2%）同量級」。
   `config_11x5_credit.js` 目前只有第一~五球／總和／龍虎鬥／全5中1 四種玩法，
   **沒有** eggs／k3／ssc 那種現成的「豹子」圖案概念，需要重新從機率窮舉候選（例如全5中1某特定號、總和極值等），
   不可比照 eggs 決策直接套用「豹子」。
2. **weight 分級**：沿用 6hc 的理論賠率分級法（`1/命中機率` ≥20→3、2.5~20→2、<2.5→1），
   逐項對照 11x5-CD 各注項理論賠率標（第一~五球每項機率 1/11，總和／龍虎鬥／全5中1 需個別核對）。

### 6.3 關聯機制（需求核心，務必落實）

- 設定檔宣告 weight（group 層預設 + item 層覆寫）
- 注單需存 `playKey` + `tabId` + `betCode` + `odds`（既有 `orders.ts` 已支援，不需改）
- 結算時用 `(playKey, tabId, betCode)` 反查 weight，解析順序 `item.weight → group.weight → 0`
  ⚠️ **明確 `weight: 0`（排除在彩池外）與「完全沒設定」（退回 `weightFallback`）是兩件不同的事**，
  必須用 `== null` 判斷，不可用 falsy 判斷（此語意在 `shared/config/jackpot.ts` 也要守一次）

官方盤（OF）不接彩池，`current.get.ts` 不需要加 `pool` 欄位（同 eggs 的做法）。
