# add-tower-defense-game

遊戲中心新增 **TOWER DEFENSE**（TD 塔防），是遊戲中心目前唯一的塔防類型玩法，明確定位為「好玩優先於美術」的 MVP：玩家在固定地圖上放置弓箭塔／炮塔／冰塔，抵禦沿路徑前進的普通怪／快速怪／Tank／Boss，透過擊殺取得 Gold 建塔與升級（每種塔 3 級），並在每波清完後從 3 個隨機強化中選 1（攻擊力／攻速／Gold 收益／射程／減速強度）。**波次為無限（Endless）模式**：第 1～20 波是手工設計的教學/難度曲線，第 21 波起改由程序化生成、難度持續遞增，沒有「破關」終點，Boss 每 10 波固定出現一次（10、20、30…），玩家只能靠 HP 歸零結束一局，重點在挑戰「能撐到第幾波」。全程使用 DOM + CSS 呈現（**不使用 Canvas／WebGL**），沿用專案既有極簡像素風。

本次僅產出 OpenSpec 提案文件，**不撰寫任何程式碼**；design.md 依專案既有 16+ 款遊戲的實作慣例（單一 `xxxEngine.ts` + 單一頁面 `.vue`，不拆多檔/多元件）盤點架構決策，並記錄地圖/數值/波次/強化系統的設計草案（Phase 9 才做最終數值平衡）。遊戲主題色採 `#6a994e`（橄欖綠，貼近塔防草地意象，不與既有遊戲撞色），game-hall 入口登記為 `id: 25`、路徑 `/game/tower-defense`。
