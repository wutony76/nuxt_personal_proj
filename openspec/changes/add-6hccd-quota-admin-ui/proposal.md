# Proposal

## 變更名稱

`add-6hccd-quota-admin-ui` — 6hc-cd 跨分頁單期總上限後台 UI

## 背景

`add-6hccd-quota-p2`（已完成並驗證通過）刻意把後台 UI 留到下一個 change，當時只做了 3 支
admin API（全站設定 GET/PATCH、個別玩家 PATCH）。使用者現在要求接續處理這塊。

## 範圍

`/admin/bg-lottery` 新增第 4 個分頁「限額設定」（既有 3 個分頁：保底超付事件／池底重骰事件／
各彩種摘要），比照既有 `NpcPanel.vue` 的「全域設定 + 逐會員覆寫列表」版面：
- 上半部：全站預設跨分頁單期總上限（輸入框 + 儲存）
- 下半部：可搜尋會員（重用既有 `api.admin.roles()`，不新增會員清單端點）、逐會員設定/清除
  個別覆寫值

## 不包含

- 不新增後端邏輯（3 支 API 已在 `add-6hccd-quota-p2` 完成，這次純前端）
- 不做批次匯入/匯出覆寫清單

## 驗證方式

- 設定全站預設值，確認儲存成功且重新整理後維持
- 搜尋會員、設定個別覆寫值，確認列表正確顯示、清除覆寫後正確消失
- `isDemo` 唯讀模式下寫入控制項正確被鎖住（比照既有頁面慣例）

## 成功標準

- [x] 新分頁完成，UI 可完整操作既有 3 支 API
- [x] 既有測試無回歸
