## 3. Step 1 - Config Conversion

讀取 bglottery 的 SSC 玩法設定。

將其轉換成本專案既有 conf 格式。

1. 找到對應玩法 UI
2. 分析 UI 使用的欄位
3. 由既有 UI 行為反推出必要 config
4. 補齊 conf
5. 不可自行發明玩法規則
